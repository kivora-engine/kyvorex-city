# Kyvorex City

**Livre vite. Sème la police.**

Jeu rétro vu de dessus, jouable directement dans le navigateur. Tout le jeu est dessiné et sonorisé en code (HTML5 Canvas et Web Audio), sans aucune librairie. Seules les images de présentation (icône et aperçu de partage) sont des fichiers.

## Comment jouer

- Sur mobile : boutons tactiles en bas de l'écran.
- Sur ordinateur : flèches du clavier ou W A S D.
- Objectif : ramasser le colis, le livrer avant la fin du chrono.
- Évite les chocs violents : ils attirent la police, et une arrestation termine la partie.
- Le meilleur score est sauvegardé dans ton navigateur.
- Le bouton ♪ en bas de l'écran coupe ou remet le son.
